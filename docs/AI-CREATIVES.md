# AI advertising creatives
Set SARAH_IMAGE_ENABLED=true, OPENAI_API_KEY, optionally SARAH_IMAGE_MODEL (default gpt-image-1.5) and SARAH_IMAGE_DAILY_LIMIT (default 3, maximum 10). POST /api/v1/marketing/creatives with brief, size (1024x1024, 1024x1536 or 1536x1024), confirmed=true. Paid calls are reserved atomically per UTC day and counted even on failures. Returns a private owner-authenticated PNG URL, stored in PostgreSQL. GET lists results, DELETE removes a completed asset. Generation is paused by the global kill switch. Images require human review and separately approved hosting before using as an Instagram image URL. No automatic ad spend or public hosting. Requires a real provider key/model entitlement. No live paid generation performed in development.
