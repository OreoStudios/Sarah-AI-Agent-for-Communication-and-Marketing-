# Social publishing

Enable `SARAH_SOCIAL_LINKEDIN_ENABLED=true` or `SARAH_SOCIAL_FACEBOOK_ENABLED=true`. Set respective `SARAH_LINKEDIN_API_VERSION` (YYYYMM) or `SARAH_FACEBOOK_API_VERSION` (vNN.N) to a supported version. Add api.linkedin.com / graph.facebook.com to SARAH_OUTBOUND_HOSTS. Create channel with config JSON `{\"author\":\"urn:li:organization:123\"}` or `{\"pageId\":\"123\"}` and approved access token as secret. Connection only indicates valid configuration, not verified publishing rights. Reconcile ambiguous deliveries manually. Use official OAuth scopes and authorized accounts. Instagram and Reddit remain mock. See https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api and https://developers.facebook.com/docs/graph-api/reference/page/feed/.
