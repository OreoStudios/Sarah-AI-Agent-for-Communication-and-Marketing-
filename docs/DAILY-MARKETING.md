# Daily marketing planning
Set SARAH_DAILY_PLAN_ENABLED=true, SARAH_DAILY_OBJECTIVE, SARAH_DAILY_AUDIENCE, SARAH_DAILY_PLATFORMS (comma-separated allowed platforms), SARAH_DAILY_LANGUAGE (en/fr), SARAH_DAILY_MAX_CHANNELS (1–3). Configure a live LLM. Default run time 07:30 Europe/Paris. The planner claims one run per day across replicas, rotates brand service focus, generates real campaign drafts, applies compliance checks, selects eligible channels using measured performance weights with exploration, and persists run results. Set SARAH_DAILY_AUTO_PUBLISH=true only after reviewing output and approving connected destinations; it schedules strictly passing content on Discord, LinkedIn, Facebook or WordPress with existing scheduler safeguards. Instagram and Reddit always require owner review; email campaigns never auto-send. Default is draft-only. POST /api/v1/marketing/daily triggers the same daily job, GET returns history. No budget changes, external ad purchases, or promises of sales. Review failed runs before proceeding. Performance weights depend on real owner-supplied observations.
