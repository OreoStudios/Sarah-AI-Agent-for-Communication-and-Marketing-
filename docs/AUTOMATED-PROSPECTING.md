# Automated prospect discovery
Owner POST /api/v1/prospects/acquisition with query, optional postalCode and required activityPrefix (e.g. 43.22). One bounded registry search per Paris day, at most 10 records, deduplicated by SIREN, skips non-public records and individual entrepreneurs. Existing records (including suppressed records) are not modified. Set SARAH_PROSPECTING_ENABLED=true, SARAH_PROSPECTING_QUERY, SARAH_PROSPECTING_ACTIVITY_PREFIX, optionally SARAH_PROSPECTING_POSTAL_CODE, SARAH_PROSPECTING_CRON for daily discovery. GET same endpoint shows runs; review leads in CRM. No email harvesting, unsolicited outreach, automatic contact or guaranteed sales. Qualification is a transparent sector/location heuristic, not purchase intent. French public registry only.
