# Permission-based marketing email
Disabled by default. Configure real SMTP, SARAH_EMAIL_MARKETING_ENABLED=true, SARAH_MARKETING_FROM, SARAH_MARKETING_REPLY_TO (monitored inbox), SARAH_MARKETING_POSTAL_ADDRESS, SARAH_MARKETING_PUBLIC_URL (public HTTPS origin), SARAH_MARKETING_EMAIL_DAILY_LIMIT (1–50, default 10). Record demonstrable consent via POST /api/v1/marketing/email/subscribers. Never import scraped addresses. Create a draft via POST /drafts with subject, objective, language; GET /drafts to review. POST /drafts/{id}/send with explicit confirmed=true and a specific recipient list. Each recipient is checked against persistent opt-outs; Recipients can unsubscribe using the opaque token link (GET confirmation, POST immediate suppression), or by reply; the owner must process reply opt-outs promptly via POST /unsubscribe. The email includes sender identity, an unsubscribe link and RFC 8058 one-click headers. Configure DKIM with the SMTP provider. SMTP acceptance is not delivery confirmation; ambiguous sends are never automatically retried. GET /drafts/{id}/deliveries shows status. No tracking pixels or bulk unsolicited campaigns. Use a monitored mailbox; automated bounce/complaint webhook processing is not yet implemented. Do not enable where your provider or law requires those capabilities without adding them.
